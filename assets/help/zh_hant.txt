1. 用途

Games_translator 讀取選定遊戲視窗區域的文字。OCR（文字辨識） 辨識字元，翻譯器處理文字，懸浮窗顯示結果。Offline 使用本機模型，Online 使用外部服務。Live 持續監看固定區域，Dynamic 依需求翻譯一次選取範圍。

2. 快速開始

1) 開啟遊戲，按兩下 Games_translator.exe。
2) 從清單選擇遊戲視窗，找不到時按「更新」。
3) 以頂端按鈕選擇語言區塊，並確認原文和譯文語言。
4) 選擇 offline 或 online。使用 online 時，開啟線上翻譯設定並設定服務。
5) 使用 offline 時，依區塊選擇本機翻譯器或翻譯設定，檢查可用的 OCR 及「快速鍵」中的按鍵。
6) 可以載入已儲存的遊戲設定檔；載入後請確認還原的設定。啟動器準備啟動懸浮翻譯時，會為新遊戲建立設定檔。
7) 啟動懸浮翻譯並等待 OCR 及翻譯器就緒。
8) 在設定模式中將框拖至文字上，使用右下角調整大小。
9) 按指定的「設定 / 翻譯」快速鍵進入 Live。獨立 Dynamic 模式可略過 Live 辨識框設定，直接使用 Dynamic 快速鍵。

3. 語言區塊

這是同一個程式的三種模式：
Block 1: EN → RU / UK
Block 2: JA / ZH-CN / ZH-TW → EN / RU / UK
Block 3: EN → JA / ZH-CN / ZH-TW

4. 翻譯模式

Fast 優先速度與較低負載，但可能有誤譯或不自然的表達。Quality 著重品質，通常增加延遲與負載。Block 1 的自動選項使用 Bergamot，TranslateGemma Q6 屬於 Quality；Block 2 和 3 有 Fast / Quality 設定。

Online 需要網路、已設定的服務，以及必要時的 API 金鑰。服務可能限流、收費或傳回錯誤。整合自動測試已通過，但不是每項服務都使用真實帳號驗證。

5. OCR（文字辨識）

Tesseract 用於英文。Paddle Fast 較輕，Paddle Full 較重。CJK Paddle Fast 用於 Block 2 的日文和中文。可選項目隨區塊、模式與字幕背景改變，不保證各遊戲的速度和辨識效果相同。

6. Live 與 Dynamic

在 Edit 模式移動或調整辨識框，Live 持續監看此區域。指定快速鍵可隱藏或顯示譯文；強制更新會重新執行一次 Live 辨識與翻譯。

Dynamic 可不開啟 Live 而單獨使用，也可與 Live 搭配使用。遊戲文字除了字幕，還出現在任務、對話、選單、物品說明和介面時，建議同時使用兩種模式。Live 持續翻譯主要區域，Dynamic 則可視需要用滑鼠框選視窗中的其他區域。

啟用 Dynamic 的組合或獨立模式後，按其快速鍵並以滑鼠框選文字。Esc 取消選取。再次按 Dynamic 快速鍵可取消選取或等待，或關閉結果。

7. 快速鍵

在快速鍵設定中修改設定 / 翻譯、顯示 / 隱藏、Dynamic 和強制更新。使用目前設定檔的指派，避免與遊戲快速鍵衝突。

8. 譯文外觀

文字設定可調整大小、顏色、描邊和背景板透明度。Dynamic 的 Auto-Fit 自動調整結果視窗與字級。自適應背景板僅用於 Live：取樣原文字幕的純色背景並覆蓋原文。背景不均勻時不保證結果。Dynamic 使用手動背景設定。

9. 設定檔與 Translation Memory

遊戲設定檔儲存區域、語言、OCR、翻譯器、外觀和快速鍵。下次可重新選取；正常關閉懸浮窗會儲存區域變更。文字和翻譯路徑設定相符時，本機 TM 可重用既有譯文。

10. 硬體

適用於 Windows 10/11。NVIDIA 是主要測試平台。提供 Vulkan 路徑，但 AMD 未完成真實硬體驗證，Intel 尚未測試。Offline Quality 可能消耗較多資源。

11. 診斷

「詳細日誌」預設關閉。排查錯誤時可開啟，下次啟動懸浮層時生效。
工作階段日誌目錄：
{logs_path}
分享前請檢查日誌，可能包含遊戲文字、譯文和技術資訊。請另閱「重要說明」中的限制與反作弊風險。

12. 常見問題

• 找不到遊戲視窗：開啟遊戲、按「更新」，必要時嘗試視窗或無邊框模式。
• 辨識不到文字：縮小框選區域，檢查語言及 OCR。
• 翻譯器尚未就緒：等待準備完成，若失敗請檢查本機資源或 Online 設定。
• Online 錯誤：檢查網路、服務、模型、金鑰及配額。
• Quality 太慢：改用 Fast 或較輕的本機翻譯器。
• 沒有字幕：檢查 Live、可見性及框內文字。
• 快速鍵無效：檢查設定檔的指派、遊戲按鍵衝突及就緒狀態。
