1. 用途

Games_translator 从选定的游戏窗口区域读取文字。OCR（文字识别） 识别字符，翻译器处理文字，悬浮窗显示结果。Offline 使用本地模型，Online 使用外部服务。Live 持续监看固定区域，Dynamic 按需翻译一次选区。

2. 快速开始

1) 打开游戏，双击 Games_translator.exe。
2) 在列表中选择游戏窗口，找不到时点击“更新”。
3) 使用顶部按钮选择语言区块，并确认原文与译文语言。
4) 选择 offline 或 online。使用 online 时，打开在线翻译设置并配置服务。
5) 使用 offline 时，按区块选择本地翻译器或翻译配置，并检查可用 OCR 与“快捷键”中的按键设置。
6) 可在列表中加载已保存的游戏配置；加载后请核对恢复的设置。启动器准备启动悬浮翻译时会为新游戏创建配置。
7) 点击启动悬浮翻译，等待 OCR 和翻译器准备好。
8) 在设置模式下，将框拖到文字上，使用右下角调整大小。
9) 按已分配的“设置 / 翻译”快捷键进入 Live。独立 Dynamic 模式无需设置 Live 识别框，直接使用 Dynamic 快捷键。

3. 语言区块

这是同一程序的三个模式：
Block 1: EN → RU / UK
Block 2: JA / ZH-CN / ZH-TW → EN / RU / UK
Block 3: EN → JA / ZH-CN / ZH-TW

4. 翻译模式

Fast 优先速度和较低负载，但可能有误译或表达不自然。Quality 注重译文质量，负载和延迟通常更高。Block 1 的自动选项使用 Bergamot，TranslateGemma Q6 属于 Quality；Block 2 和 3 使用 Fast / Quality 配置。

Online 需要联网、配置服务，并在需要时提供 API 密钥。服务可能限流、收费或返回错误。集成自动测试已通过，但并非所有服务均使用真实账号验证。

5. OCR（文字识别）

Tesseract 用于英文；Paddle Fast 较轻，Paddle Full 较重。CJK Paddle Fast 用于 Block 2 的日文和中文。可选项随区块、模式和字幕背景变化，不保证每款游戏的速度或识别效果相同。

6. Live 与 Dynamic

在 Edit 模式移动、调整识别框；Live 持续监看该区域。使用已分配的快捷键显示或隐藏译文。“强制刷新”重新执行一次 Live 识别与翻译。

Dynamic 可以脱离 Live 单独使用，也可以与 Live 同时使用。游戏文字不只出现在字幕区，还出现在任务、对话、菜单、物品说明和界面中时，建议同时使用两种模式。Live 继续翻译主区域，Dynamic 则可按需用鼠标框选窗口中的其他区域。

启用 Dynamic 的组合或独立模式，按其快捷键并用鼠标框选文字。Esc 可取消选区。再次按 Dynamic 快捷键可取消选区或等待中的任务，或关闭结果。

7. 快捷键

在“快捷键”中修改设置 / 翻译、显示 / 隐藏、Dynamic 和强制刷新。以当前配置中的按键为准，避免与游戏按键冲突。

8. 译文外观

文字设置可调整大小、颜色、描边和背景板透明度。Dynamic 的 Auto-Fit 自动调整结果窗口和字号。自适应背景板只用于 Live：采样原文字幕的纯色背景并盖住原文。背景不均匀时不保证效果。Dynamic 使用手动背景设置。

9. 配置与 Translation Memory

游戏配置保存区域、语言、OCR、翻译器、外观和快捷键。下次可重新选择；正常关闭悬浮窗时保存区域修改。本地 TM 可以在文本和翻译路线设置匹配时复用已有译文。

10. 硬件

面向 Windows 10/11。NVIDIA 是主要测试平台。程序支持 Vulkan 路线，但 AMD 未完成真实硬件资格验证，Intel 未测试。Offline Quality 可能占用较多资源。

11. 诊断

“详细日志”默认关闭。排查问题时可启用，从下一次启动悬浮层起生效。
会话日志目录：
{logs_path}
发送日志前请检查内容，其中可能包含游戏文字、译文和技术信息。请另外阅读“重要说明”中的限制和反作弊风险。

12. 常见问题

• 找不到游戏窗口：启动游戏，点“更新”，必要时试用窗口或无边框模式。
• 识别不到文字：缩小区域，检查语言和 OCR。
• 翻译器未就绪：等待准备；失败时检查本地资源或在线配置。
• Online 报错：检查网络、服务、模型、密钥和限额。
• Quality 太慢：改用 Fast 或更轻的本地翻译器。
• 没有字幕：检查 Live、可见性和框内文字。
• 快捷键无效：检查配置中的按键、游戏冲突及就绪状态。
