1. アプリについて

Games_translator はゲームウィンドウ内の指定範囲を読み取ります。OCR（文字認識） が文字を認識し、翻訳エンジンの結果をオーバーレイに表示します。Offline はローカルモデル、Online は外部サービスを使用します。Live は固定範囲を監視し、Dynamic は選択範囲をその都度翻訳します。

2. クイックスタート

1) ゲームを開き、Games_translator.exe をダブルクリックします。
2) ゲームウィンドウを選択します。一覧にない場合は「更新」を押します。
3) 上部のボタンで言語ブロックを選び、原文と翻訳先の言語を確認します。
4) offline または online を選びます。online の場合はオンライン翻訳設定でサービスを設定します。
5) offline の場合はブロックに応じてローカル翻訳エンジンまたは翻訳プロファイルを選び、OCR と「ホットキー」の割り当てを確認します。
6) 保存済みのゲームプロファイルを選ぶと設定が復元されます。復元された設定を確認してください。新しいゲームではランチャーがオーバーレイの起動を準備する際にプロファイルを作成します。
7) 「オーバーレイを起動」を押し、OCR と翻訳エンジンの準備を待ちます。
8) 設定モードで枠を文字に合わせ、右下のつまみでサイズを調整します。
9) 割り当てた「設定 / 翻訳」キーで Live を開始します。Dynamic 単独モードでは Live の枠設定を省略し、Dynamic キーを使います。

3. 言語ブロック

一つのアプリにある三つのモードです。
Block 1: EN → RU / UK
Block 2: JA / ZH-CN / ZH-TW → EN / RU / UK
Block 3: EN → JA / ZH-CN / ZH-TW

4. 翻訳モード

Fast は速度と軽さを優先しますが、誤訳や不自然な表現があり得ます。Quality は品質を重視する分、負荷と待ち時間が増えます。Block 1 の自動選択は Bergamot、Quality は TranslateGemma Q6 の選択肢を使用します。Block 2 と 3 には Fast / Quality プロファイルがあります。

Online にはネット接続とサービス設定が必要で、サービスによっては API キーも必要です。利用制限、料金、エラーは提供元によって異なります。統合の自動テストは通過していますが、全サービスで実アカウントを検証したわけではありません。

5. OCR（文字認識）

Tesseract は英語用です。Paddle Fast は軽量、Paddle Full はより負荷の高い選択肢です。CJK Paddle Fast は Block 2 の日本語と中国語用です。候補はブロック、モード、字幕背景によって変わり、ゲームごとに速度と精度も異なります。

6. Live と Dynamic

Edit では認識枠を移動、拡大縮小できます。Live では枠内を監視します。表示切り替えで翻訳を隠す、または表示できます。強制更新は現在の Live 範囲を再認識し、翻訳します。

Dynamic は Live なしで単独でも、Live と併用しても使えます。字幕以外にもクエスト、会話、メニュー、アイテム説明、画面 UI にテキストが出るゲームでは、併用がおすすめです。Live がメインの範囲を翻訳し続ける一方、必要なときに Dynamic で別の範囲をマウスで選択できます。

Dynamic を併用または単独で有効にし、割り当てたキーを押して文字をドラッグで囲みます。Esc は範囲選択を中止します。同じ Dynamic キーをもう一度押すと選択や処理待ちを中止、または結果を閉じます。

7. ホットキー

「ホットキー」で設定 / 翻訳、表示 / 非表示、Dynamic、強制更新のキーを変更できます。現在のプロファイルの割り当てを使い、ゲーム側のキーとの競合を避けてください。

8. 表示設定

テキスト設定でサイズ、色、縁取り、背景の透明度を変更できます。Dynamic の Auto-Fit は結果ウィンドウとフォントサイズを調整します。背景プレートモードは Live 専用です。元の字幕の単色背景を取得し、元の文字を覆います。不均一な背景では結果を保証できません。Dynamic は手動の背景設定を使用します。

9. プロファイルと Translation Memory

ゲームごとに範囲、言語、翻訳エンジン、OCR、外観、キーを保存します。次回はプロファイルを選び直せます。範囲の変更は通常のオーバーレイ終了時に保存されます。ローカル TM は文字列と翻訳経路の設定が一致すると以前の翻訳を再利用できます。

10. ハードウェア

Windows 10/11 向けです。NVIDIA が主な検証環境です。Vulkan の経路はありますが、AMD は実機での完全な検証を行っておらず、Intel は未検証です。Offline Quality は多くのリソースを消費する場合があります。

11. 診断

「詳細ログ」は既定でオフです。問題調査のために有効にすると、次回のオーバーレイ起動から記録します。
セッションログの場所:
{logs_path}
共有前にゲーム内の文字、翻訳、技術情報が含まれていないか確認してください。制約とアンチチートのリスクは別の「重要」ダイアログにあります。

12. よくある問題

• ゲームが一覧にない: ゲームを起動し「更新」。必要に応じてウィンドウまたはボーダーレス表示を試します。
• OCR が読めない: 枠を文字に合わせ、言語と OCR を確認します。
• 翻訳準備中: 準備を待ち、失敗時はローカルリソースまたは Online 設定を確認します。
• Online エラー: ネット接続、サービス、モデル、キー、利用制限を確認します。
• Quality が遅い: Fast または軽量なローカル翻訳エンジンを試します。
• 字幕が出ない: Live、表示状態、枠内に文字があるか確認します。
• キーが反応しない: 現在の割り当て、ゲームとの競合、翻訳の準備状態を確認します。
